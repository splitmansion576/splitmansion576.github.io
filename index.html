📋 About This Application

This is a complete reference package for people who want to adjust their Hot Wheels Infinite Rush gaming experience on Windows. It contains a detailed Cheat Engine table – a kind of "map" that shows you exactly which values in the game's memory control things like speed, boost, or score.

💡 What is a Cheat Table?
Think of it as a dictionary that translates between what you see on screen (like a score of 100) and what your computer is actually storing (a number in memory). This table helps you edit those numbers safely and in a guided way.

Because every game update can change how things work, this package includes game-build matching notes so you know which game version the table was originally designed for. There are also value type explanations (like integers, floats, or text) to help you understand what you're editing. And most importantly, there are offline test records – detailed logs showing how the table behaved during testing without an internet connection, so you know exactly what to expect.

⚠️ IMPORTANT NOTE: This is a reference package. The table itself hasn't been verified to work, and the developer clearly states that no working table is confirmed. Think of it as a starting point for your own research and learning.
